# neq, iOS Liquid Glass 목업 의뢰서

작성일: 2026-11-19  
단계: 디자인 탐색. 이 문서는 구현 승인이나 소스 변경 지시가 아니다.

## 디자인 에이전트에게 전달할 요청

> neq, iOS 앱의 현행 화면을 기준으로 Liquid Glass 적용 목업을 제작해 주세요. `DESIGN.md`의 Quiet Ink와 포스터 중심 위계를 유지하면서, 내비게이션 및 소수의 상단 조작부에 유리 재질을 적용하는 두 안을 비교해 주세요. 화면 전체에 유리 효과를 반복하거나 브랜드를 밝고 차가운 톤으로 바꾸지 마세요. 아래 화면과 상태를 같은 iPhone 크기로 나란히 보여 주고, 터치 영역·명도·콘텐츠 가림을 검토해 주세요. 아직 앱 소스는 수정하지 않습니다.

## 제품과 현재 구조

- 제품: OTT 작품을 스와이프하며 발견하고, 큐를 만들고, 저장하는 iOS 앱. `apps/native`는 Expo SDK 54 / Expo Router 6 / React Native 0.81 기반이다.
- 디자인 기준: [DESIGN.md](../DESIGN.md). 현재 방향은 **Quiet Ink**다. 배경 `#12110E`, 서피스 `#1A1916`, 기본 텍스트 `#EDEDEF`, 절제된 앰버 `#C4A35A`를 사용한다. 포스터가 주인공이며 UI는 조용해야 한다. 실제 토큰은 [tokens.ts](../packages/design/src/tokens.ts)에 있다.
- 현행 하단 구조: **발견 / 큐 / 저장 / 검색** 네 슬롯. 발견·큐·저장은 화면 전환, 검색은 현재 화면 위에 `SearchSheet`를 여는 액션이다. 프로필은 각 화면 헤더 우상단에서 진입한다. 기준 구현은 [app/_layout.tsx](../apps/native/app/_layout.tsx)다.
- 현행 탭 바: 불투명한 `surface` 배경, 상단 경계선, 높이 72, 아이콘+라벨, 활성 앰버. 탭 전환 애니메이션은 없고 누름 피드백은 opacity/scale이다.
- 발견 화면: 워드마크·선택적 페르소나 칩·프로필 버튼, 필터 행, 큰 스와이프 카드, 하단 5개 액션 버튼. [app/index.tsx](../apps/native/app/index.tsx), [DiscoverHeader.tsx](../apps/native/components/DiscoverHeader.tsx).
- 큐 화면: `Que` 헤더, 최근 저장작·장르·감독 테마. 큐를 고르면 발견 화면에 큐 덱이 열린다. [app/mix.tsx](../apps/native/app/mix.tsx).
- 저장 화면: `Saved` 헤더, 그리드/리스트 전환, 필터와 포스터 목록. [app/saved.tsx](../apps/native/app/saved.tsx).
- 검색: 하단 검색 슬롯을 누르면 현재 화면 위에 검색 시트가 열린다. 검색 결과 작품 선택 시 상세 시트와 복귀 흐름이 있다. [SearchSheet.tsx](../apps/native/components/SearchSheet.tsx).
- 상세: 포스터/스틸이 주역인 바텀시트. [DetailSheet.tsx](../apps/native/components/DetailSheet.tsx).

## 목업에서 탐색할 변경점

| 영역 | 현재 | 목업에서 검토할 방향 |
|---|---|---|
| 하단 탭 바 | 화면 폭 전체의 불투명한 띠 | 콘텐츠 위에 떠 있는 iOS 네이티브 재질. 발견·큐·저장의 계층과 검색 액션의 성격 차이를 드러낼 것 |
| 활성 탭 | 아이콘/라벨 앰버 | 유리 재질의 선택 상태와 앰버의 균형. 앰버가 한 화면에 과하게 늘지 않도록 할 것 |
| 헤더 버튼 | 다크 배경 위 단독 아이콘 | 프로필·닫기 등 필요한 소수의 조작부에만 유리 재질을 시험할 것. 워드마크와 페르소나 칩은 브랜드 인지가 우선 |
| 카드·포스터 | 이미지와 텍스트가 화면 중심 | 카드 자체에는 유리 효과를 씌우지 말 것. 하단 액션 바와 탭 바의 시각적 충돌만 검토할 것 |
| 검색·상세 시트 | 다크 서피스의 모달 | 시트 가장자리/핸들/상단 버튼의 재질만 시험할 것. 입력칸과 긴 텍스트의 읽기 쉬움이 우선 |

### 비교안

1. **A — 시스템 중심:** iOS 26의 네이티브 탭 바 표현을 기준으로 한다. 상단 헤더와 시트는 현행 Quiet Ink에 가깝게 둔다. Apple 플랫폼의 익숙한 조작감과 가장 낮은 시각적 소음을 확인하는 안이다.
2. **B — 브랜드 조화:** 동일한 탭 구조에 따뜻한 중성 톤과 얇은 앰버 선택 표현을 조절한다. 헤더의 프로필 버튼과 시트 상단 버튼 일부에 재질을 연장한다. 포스터와 탭 바의 위계가 유지되는지 A와 비교한다.

각 안은 **현행 → 변경안** 비교가 가능하도록 같은 콘텐츠와 기기 크기를 사용한다. 글래스 강도, 틴트, 선택 상태, 배경 처리에 대한 수치/색상/레이어 설명을 함께 제시한다. 시각 효과를 CSS 블러만으로 흉내 낸 이미지는 최종 iOS 동작의 증거로 취급하지 않는다.

## 필수 화면과 상태

1. **발견 기본:** 밝은 포스터와 어두운 포스터를 각각 사용. 탭 바가 이미지·액션 바 위에서 어떻게 읽히는지 확인.
2. **큐 및 저장:** 큐의 테마 카드, 저장의 포스터 그리드와 스크롤 끝 상태. 바가 콘텐츠를 가리거나 클릭 영역을 침범하지 않는지 확인.
3. **검색 열림:** 발견/저장에서 검색 슬롯을 누른 직후, 키보드가 열린 상태, 검색 결과에서 상세로 이동 후 되돌아온 상태. 검색은 화면 전환이 아니라 시트라는 현재 동작을 반영.
4. **상세 시트:** 포스터가 밝은 경우와 어두운 경우, 시트가 올라왔을 때 탭 바와 시트의 겹침·우선순위.
5. **환경 차이:** iOS 26 글래스 지원, 이전 iOS의 정적 대체 표현, 투명도 줄이기 설정, 큰 글자/좁은 화면.

## 판단 기준

- 발견의 포스터가 첫 시선의 중심이고, 탭 바는 탐색을 돕되 주인공이 되지 않는다.
- 아이콘과 라벨은 밝은/어두운 포스터 양쪽에서 읽힌다. 상태를 색만으로 구분하지 않는다.
- 모든 조작부의 터치 영역은 최소 44×44pt이며, 홈 인디케이터·하단 액션 바·스크롤 콘텐츠와 충돌하지 않는다.
- 검색의 별도 액션 성격과 프로필의 헤더 진입이 분명하다. 큐(`Que`)의 이름과 현재 네 슬롯은 유지한다.
- 유리 효과는 내비게이션과 소수 컨트롤에 집중한다. 포스터 카드, 긴 본문, 필터 칩 전체를 유리로 덮지 않는다.
- 모션은 절제하고 투명도/동작 줄이기 환경에서도 정보와 동작을 잃지 않는다.
